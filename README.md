# 🩸 UAP Blood Connect

A modern web platform for connecting blood donors and recipients efficiently.  
Built with React, TypeScript, and Vite, this application helps users find donors, post blood requests, and track donation activity.

---

## 🚀 Features

- 🔍 Search and find blood donors
- 📝 Post blood requests
- 📊 Leaderboard for top donors
- 🧑‍🤝‍🧑 Donor profiles
- 📱 Responsive UI (mobile-friendly)
- ⚡ Fast performance using Vite

---

## 🛠️ Tech Stack

- **Frontend:** React + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Package Manager:** npm / Bun
